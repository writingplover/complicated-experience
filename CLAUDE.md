# Air Stage — play "Complicated" like the crowd is really watching

## Start here

**Before every action, read `PROJECT.md`.** It holds the current status, the decisions made so
far, and the approved design. When you decide something or finish a milestone, update
`PROJECT.md` in the same commit. If `PROJECT.md` and this file disagree, `PROJECT.md` wins on
*what* we build; this file wins on *how* we work.

## The project

A full-screen browser experience around Avril Lavigne's "Complicated" (album *Let Go*, 2002).
The player plays air guitar in front of a laptop webcam; MediaPipe Pose tracks the movement; an
energy score drives a virtual crowd made of three video loops from bored to wild; the run ends on
a downloadable hero frame. Built in one short session. Proof of concept, not a production app.

## Stack

- Vite + TypeScript, plain DOM, CSS and Canvas. No framework, no UI or animation libraries.
- `@mediapipe/tasks-vision` is the only runtime dependency. Model and WASM load from CDNs.
- pnpm. Install with `pnpm install --ignore-scripts`. Packages must be at least 3 days old.
- Adding a dependency is a decision: log it in `PROJECT.md` first.

## Working in the repo

1. **One module per concern** under `src/stage/`. Static layers live in `index.html`, wiring in
   `src/main.ts`. Keep modules small and free of globals; pass functions and elements in.
2. **Commit small, commit often, straight to `main`.** Conventional commit messages scoped to the
   module: `feat(energy): add hysteresis`. Before every push: `git pull --rebase` then `git push`.
3. **Never force-push. Never rewrite `main` history.**
4. **Run `pnpm typecheck` before you commit.** No test suite exists; say so when you skip tests.
5. **Everything degrades.** Missing camera, missing song, missing crowd clips, failed model load:
   the stage still runs and says what is missing. Demo mode (`?demo`) must always work.
6. **Keep it light.** Crowd clips under 15 MB each, everything else under 2 MB.
7. **Respect reduced motion** via `prefersReducedMotion()` in `src/stage/prefs.ts`: no shake, no
   strobes.

## Copyright and privacy

- The recording is **never committed**. It lives at `public/local/complicated.mp3`, which is
  gitignored, and audio files are ignored repo-wide. The repo is public: check `git status`
  before every commit.
- No lyrics beyond a short fragment, no official artwork, no ripped video.
- Crowd clips are generated by us and may be committed. Stock footage may not.
- Camera frames and pose data stay in the browser. No recording, no upload, no analytics. The UI
  says so next to the camera prompt. Ask for the camera on a key press or click, never on load.

## Commands

- `pnpm dev` — dev server with hot reload (`http://localhost:5173`, add `?demo` to skip the camera)
- `pnpm typecheck` — `tsc --noEmit`
- `pnpm build` — typecheck + production build to `dist/`
